ZAKOPEDIYA MINI APP — 1-bosqich (Supabase faktlar)

FAYLLAR
- index.html
- style.css
- app.js

JOYlashtirish
1. GitHub'dagi m0n4rch-404/zakope repozitoriyasini oching.
2. Eski saytning root papkasidagi index.html faylini almashtirmang.
3. Repozitoriyada miniapp nomli yangi papka yarating.
4. Ushbu ZIP ichidagi ZakopediyaMiniApp papkasining ICHIDAGI uchta faylni miniapp/ papkasiga joylang.
5. GitHub'ga commit/push qiling.
6. Mini App manzili GitHub Pages yoqilgan domen ostida /miniapp/ bilan tugaydi.

XAVFSIZLIK
- app.js ichidagi sb_publishable_ kaliti brauzerda ishlatish uchun mo'ljallangan.
- service_role yoki secret kalitni hech qachon frontendga joylamang.
- Supabase'da articles jadvaliga SELECT ruxsati RLS orqali to'g'ri berilgan bo'lishi kerak.
- Ushbu versiya bazadan faqat o'qiydi; jadvalga yozmaydi, o'zgartirmaydi va o'chirmaydi.

HOZIRGI FUNKSIYALAR
- articles jadvalidan jami faktlar sonini olish
- kategoriyalar va ularning sonini chiqarish
- faktlarni 20 tadan sahifalash
- sarlavha va mazmun bo'yicha qidirish
- kategoriya bo'yicha filtrlash
- kun faktini ko'rsatish
- Telegram Mini App SDK boshlang'ich sozlamalari

ESLATMA
Bu versiya kod sintaksisi bo'yicha tekshirildi, ammo sizning Supabase loyihangiz va GitHub Pages domeningizda amaliy brauzer sinovi hali o'tkazilmadi. Joylagandan keyin sahifadagi holat xabari orqali ulanishni tekshiring.
