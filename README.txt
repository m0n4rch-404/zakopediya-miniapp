ZAKOPEDIYA MINI APP — YANGILANGAN FAYLLAR

1. index.html, app.js, style.css fayllarini GitHub’dagi zakopediya-miniapp repozitoriyingizdagi mos fayllar bilan almashtiring.
2. reyting_tarix_rpc.sql faylini Supabase → SQL Editor’da ishga tushiring.
3. Supabase’dagi mavjud register_participant, login_participant, get_random_quiz_questions va submit_quiz funksiyalari oldingi sozlash skriptidagi nom va parametrlar bilan mavjud bo‘lishi kerak.
4. quiz_questions jadvalida 800 ta savol borligini tekshiring.
5. GitHub Pages yangilangach, Telegram Mini App ichida test, profil va reytingni tekshiring.

- articles jadvali o‘zgartirilmagan.
