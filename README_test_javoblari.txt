ZAKOPEDIYA MINI APP — TEST JAVOBLARINI KO‘RSATISH YANGILANISHI

NIMA O‘ZGARDI?
- Javob tanlangach darhol tekshiriladi.
- To‘g‘ri javob yashil rangda chiqadi.
- Noto‘g‘ri tanlangan javob qizil, to‘g‘ri javob esa yashil bo‘ladi.
- Tanlangan javobni shu savolda qayta almashtirib bo‘lmaydi.
- Oldingi/keyingi savolga o‘tilganda rangli natija saqlanadi.
- Test balli, tarixi va reyting tizimi avvalgidek ishlaydi.

O‘RNATISH:
1. index.html, app.js va style.css fayllarini GitHub’dagi zakopediya-miniapp
   repozitoriyingizdagi mos fayllar bilan almashtiring.
2. Supabase -> SQL Editor -> New query bo‘limiga kiring.
3. quiz_answer_feedback.sql faylidagi kodni to‘liq joylashtiring.
4. Run tugmasini bosing (bir marta kifoya).
5. GitHub Pages deploy bo‘lishini kuting va Mini App’ni qayta oching.

Eslatma: mavjud savollar, profillar va test natijalari o‘chirilmaydi.
